The build command is **`npm run build`**, which runs `next build`.

If you're importing the GitHub repo in the Vercel dashboard, it detects Next.js and fills these in:

| Setting | Value |
|---|---|
| Framework preset | Next.js |
| Root directory | `./` |
| Build command | `npm run build` |
| Output directory | leave it on the default, `.next` |
| Install command | `npm install` |
| Environment variables | none needed |

The project also runs on Node 25 locally, and Vercel's default Node version works fine.

To run it locally, from the project folder:

```bash
cd ~/Desktop/amazonclone
npm install      # first time only
npm run dev
```

Then open **http://localhost:3000**.

To run the production build instead, which is faster and matches what Vercel serves:

```bash
npm run build
npm start        # http://localhost:3000
```

To try the full flow, add something to the cart, go to checkout and click **Continue with the demo account**. The demo account also works from the sign-in form with `demo@bazaar.in` / `demo1234`.

If port 3000 is already in use, run `npm run dev -- -p 3001`.
